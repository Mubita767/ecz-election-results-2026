# ECZ Election Results Visualization System 2026

A world-class, broadcast-quality election results visualization system developed for Zambia's Electoral Commission of Zambia (ECZ).

## Live Demo
https://jmcivymamrzsc.kimi.page

## Features
- Presidential, Parliamentary, Councilor, and Mayoral election coverage
- Interactive Zambia provincial map with real boundaries
- Opening montage with cinematic animations
- Live projection mode with fullscreen support
- Real-time data upload from control panel
- 4-election-type switcher dashboard

## Elections Covered
| Election | Total Races |
|----------|-------------|
| Presidential | 5 candidates |
| Parliamentary | 156 constituencies |
| Councilor | 3,640 wards |
| Mayoral | 122 councils |

## Technology Stack
- React 19 + TypeScript + Vite 7
- Tailwind CSS + shadcn/ui
- GSAP animations + Framer Motion
- Zustand state management
- Interactive SVG maps
